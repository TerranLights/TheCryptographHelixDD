The Cryptograph Helix development is organized into sequential phases. Each phase has a dedicated file tracking its specific goals, status, and blocking items. This file is the entry point.

## Guiding Principle

Phases are not strictly sequential — world-building, character, and plot work will overlap. The phase structure exists to prioritize: Phase 1 must be stable before Phase 3 can produce reliable beat sheets. Phase 3 must be stable before Phase 5 (drafting) begins.

The `TODO.md` at the root level is the day-to-day task list. This folder is the strategic layer — where to put effort, in what order, and why.
