# The Cryptograph Helix — Design Documentation

7-volume sci-fi novel series set in the early 3000s–3100s (deliberately fluid). A Philip K. Dick-inspired story where **Freedom** is the main character.

## Series Premise

Data encoding into DNA replaces binary computation. A "DNA Mafia" arises to protect personal information from a Silicon Valley tech-giant oligarchy that has become Earth's de facto government. Over seven books, the conflict escalates from privacy hacking to solar-system-wide warfare, culminating in the emergence of a new form of life: sentient memes.
